SAC 飛行循跡：模型、訓練與實驗結果

從 SAC+LSTM 到純 SAC（MLP），理解策略如何學習，以及本輪退步診斷的證據。

本次要回答的三個問題

01 · MODEL

SAC 如何產生與改善動作？

Gaussian actor 產生連續動作；雙 critic 評估動作價值，replay buffer 提供過去經驗，熵溫度 α 調整探索項的權重。

02 · EXPERIMENT

為什麼分成 LSTM 與 MLP？

LSTM 使用序列與記憶；MLP 是獨立從頭訓練的前饋基準。兩者同時改變了網路與序列抽樣，不能只把結果差異歸因於記憶。

03 · EVIDENCE

曾經跑滿，是否代表已穩定？

部分 checkpoint 可完成 3000 步，但後續又退步。慢 critic 子 run 在 2200 跑滿、2500 僅 163 步，尚不能宣稱已修復。

SAC：離策略、最大熵 Actor–Critic

觀測 s 經 actor 產生 Gaussian mean 與 standard deviation；SAC 內部進行動作壓縮與縮放，送入環境的動作落在 [−1, 1]。本專案不重用 PPO 的 tanh mean 網路。

1. 儲存互動經驗

環境回傳 reward、下一觀測與 done，將 (s, a, r, s′, done) 存入 replay buffer。學習時抽取過去經驗，因此採樣資料不必只來自當下策略。

此處 done 是 episode 終止訊號。訓練環境仍保留原有 isDone 語義。

2. 用雙 target Q 建立目標

y = r + γ(1 − done)
　· [min(Q̄₁(s′, a′), Q̄₂(s′, a′))
　　− α log π(a′ | s′)]

a′ 由當前 actor 在下一觀測上抽樣。Q̄ 是 target critic；終止轉移不加入未來項。這是連續動作 SAC 的單步概念式；LSTM 版本另包含序列狀態處理。

3. 改善 critic 與 actor

兩個 critic 分別靠近目標 y。Actor 使用抽樣動作的價值與熵項更新：

Jπ = E[α log π(a | s)
　　　 − min(Q₁(s, a), Q₂(s, a))]

最小化此目標會兼顧高價值動作與策略熵；不是直接挑動作網格中 Q 最大的一點。

4. 更新 α 與 target critics

α 依目標熵學習，初始 0.1，目標 −1。Target critics 透過軟更新追隨線上 critics：

ϕ̄ ← (1 − τ)ϕ̄ + τϕ
τ = 0.005

雙 Q 與緩慢 target 更新是穩定化機制，不是保證不退步的條件。

為什麼測試 MLP？

建立不含遞迴記憶的實用基準，觀察較簡單網路的訓練行為。MLP 從頭初始化，不承接 LSTM 或 PPO 的 checkpoint。

SequenceLength 32 → 1 也改變每次更新的序列資料結構，並非只改一個網路元件的等計算量因果實驗。
