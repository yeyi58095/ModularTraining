# Recurrent SAC candidate

Experimental `sac_lstm128` on the same eight-stage spatial_v2 curriculum. New
agent only; no conversion of the paused PPO run. Stage gates, reward, wind and
episode termination remain unchanged. Stage 1/2 assets are generated by
`trainingtools.prepare_progressive_v2_training` and copied into each run.

Prepare with `trainingtools.prepare_sac_trial()`. This does not start training.
The initial configuration uses at most 1000 episodes per process, checkpoints
every 100 episodes, and one attempt per explicit launch. Stage/guard decisions
may end a process earlier. Retain replay/target/optimizer data in SAC checkpoints.

The candidate uses automatic entropy tuning, two recurrent Q critics, uniform
sequence replay (32 steps), and bounded update work. It is a comparison candidate,
not proof of better flight performance or convergence. See
[trial guide](../../docs/guides/round3-next-steps-2026-10-20.md).
