# Meeting 離線展示

請把整個 `meeting_training_labstyle_20261014` 資料夾一起搬移。PPTX 與 `docs/` 應維持同層。

簡報最後一頁提供相對路徑連結，點選後由預設瀏覽器開啟 HTML。PowerPoint 可能依本機設定提示開啟外部檔案。若連結沒有開啟，直接雙擊下列檔案即可：

- `docs/diagrams/training-explorer.html`：訓練流程、內嵌程式原文與課程範例。
- `docs/architecture.html`：系統架構圖。
- `docs/index.html`：文件索引。

互動 HTML 的主要顯示不需要網路或 MATLAB。流程頁內的程式原文已內嵌；另外開啟專案原始碼的入口仍指向專案外部檔案，僅複製 docs 時不要用該入口。架構圖內的外部研究參考連結也不屬於離線展示內容。

簡報的研究結果依文件與診斷資料撰寫，最新實驗室曲線及續訓進度仍需對照使用者提供的圖。紫線表示新 run 接續，橘線表示階段切換，灰線表示 attempt 分界。環境修正與 agent 學習效果需分開判讀。
