遠端先同步程式。準備及啟動使用新收據：

```matlab
cd('D:\daniel\ModularTraining'); addpath(pwd); rehash;
receipt = fullfile(pwd,'artifacts','sac-wind-actor-half-1500-run.txt');
if ~isfile(receipt)
    source = string(strtrim(fileread(fullfile(pwd,'artifacts','sac-wind-actor-half-1100-run.txt'))));
    info = trainingtools.prepare_recovery_training(source,'configs/sac_wind_actor_half_extend_1500.json');
    writelines(string(info.sessionDir),receipt);
end
nextRun = string(strtrim(fileread(receipt)));
lineage = jsondecode(fileread(fullfile(nextRun,'recovery.json')));
assert(lineage.parent_episode==1500 && strcmp(lineage.settings.pilot,'sac_wind_actor_half_extend'));
state = jsondecode(fileread(fullfile(nextRun,'status.json')));
assert(strcmp(state.state,'paused') && state.attempt==0 && isempty(dir(fullfile(nextRun,'attempt_*'))));
retry(resume=nextRun,start=true);
```

進度使用 training_status(nextRun,50)，畫圖從 sac-wind-actor-half-1500-run.txt 讀路徑。PowerShell 在專案根目錄執行 tools/pack_sac_actor_half_1500.ps1 會核對舊收據、取得已停止來源的鎖並打包模型、課程、guard、血緣、checkpoint、attempt 與環境。ZIP 放入遠端 artifacts/packages。

本機 R2024b 使用封存的另一份 SAC Agent1500 搭配合成弱風暫停狀態驗證，完成分支準備、checkpoint SHA 相同、重載後 Stage 2 起點及 500 回合預算檢查，並以隔離副本成功產生 ZIP。真實半速 run 的保存與暫停狀態將由遠端指令核對。
