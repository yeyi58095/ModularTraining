# SAC pilot 失敗軌跡與下一個可區分實驗

2026-11-17，使用已核驗的actor pilot 120份MAT軌跡，唯讀抽出觀測、動作、位置與reward，未新增飛行或訓練。來源：`artifacts/incoming/sac-actor-pilot-20261117/payload/`，分析腳本、逐次資料、配對摘要與圖在 `artifacts/actor-pilot-causal-review-20261117/`。

## 比內部probe更具體的發現

同stage／seed，取來源與候選皆有資料的前min(steps)，排除前100個取樣（約10秒），不比較不同飛行長度的全程均值。guidance distance為觀測7×30，roll為觀測3×40度；前者不是獨立原始有限路線距離。

| 配對結果 | 基準1700對1600 | 半速1700對1600 |
|---|---:|---:|
| Guidance RMS變大的情境 | 38/40 | 38/40 |
| 平均guidance RMS：候選／來源（m） | 12.94 / 7.84 | 13.29 / 8.20 |
| 最大絕對roll變大的情境 | 28/40 | 30/40 |
| 平均絕對相鄰動作差變大的情境 | 2/40 | 2/40 |
| 平均絕對相鄰動作差：候選／來源 | 0.3487 / 0.4463 | 0.3392 / 0.4376 |
| 候選動作飽和比例的情境均值 | 0.75% | 1.18% |

兩欄來源均值不同，是各自候選終止時間不同，配對時長不同，非來源模型變動。這些結果不支持簡化成「更新後指令更抖／長時間飽和所以失敗」。更平順的動作也可能是反應不足或方向不合適，不能稱控制品質改善。

所有配對的第一筆完整10維觀測相同，但第一個正規化動作分別為來源−0.982925、基準+0.057957、半速+0.977340。初始反應已變，並非只有不同路線抽樣造成曲線不同。不據此認定第一個動作就是數十秒後失敗的充分原因。

## 下一個實驗：固定策略的探索開／關比較

目前仍未確診為actor LR、critic高估或entropy失控。已知訓練使用抽樣動作，而上述凍結飛行關閉探索，且共同輸入的Gaussian std在更新後增加。這支持先檢查「抽樣的凍結策略是否也失敗」，避免把訓練與評估差距直接等同同一種能力退步。

新入口 `trainingtools.review_sac_pilot_exploration`，由PowerShell `-ExplorationCheck` 執行。固定來源1600及兩個1700模型，只新跑探索開啟的24次CPU飛行：3模型×4seed×2風況，最多每次3000步。`explorationStdScale=1`，不額外減半。原關探索結果直接重用，沒有重跑同類內部probe或訓練。

seed固定2000011504、2000011507、2000011601、2000011602，依已知失敗情境挑選，**不是holdout或泛化測試**。本組關探索跑滿來源8/8、基準0/8、半速3/8。每情境只有一條抽樣rollout，路線seed亦控制MATLAB RNG；不宣稱各Simulink turbulence時序完全獨立，亦不把8筆當8條獨立路線。比對課程／模型／runtime／random-path SHA、實際風參數及checkpoint SHA，所有模型權重保持不變。

判讀預先限定：

- 若候選關探索失敗而開探索跑滿，屬該情境的策略執行模式落差證據；不能證明entropy是學習退步根因，亦不能以開探索結果取代原凍結升階門檻。
- 若開探索仍失敗，這些案例不支持靠抽樣救回；停止以「關探索評估方式」解釋它們。不要因此自動再降LR。
- 若來源開探索也退步，需同時報告抽樣對來源的傷害，不只挑候選改善案例。
- 單條隨機rollout不能確立期望成功率；有明顯模式後才值得設計固定路線／多獨立動作抽樣重複試驗。
