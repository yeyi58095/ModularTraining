# 純腳本從頭訓練的環境決定（2026-10-14）

## 使用者確認的方向

未來整理純腳本從頭重跑時，從第一階段、第一回合就使用目前正式的空間循跡環境。後期有風情境促成的路徑處理修正，也適用於前期無風階段，不必等到有風才啟用。

六階段共用一致的環境規則，依課程逐步增加路線難度與風擾；階段之間沿用同一個 agent。任務定位為「沿指定路徑穩定飛行，可依飛機進度更新路段」，不是追蹤按原時序移動的目標。

## 從頭重跑應保留的正式修正

- 初始化首次呼叫即提供有效完整 window。
- 已正式部署的第二版末端 lookahead 處理，依既有條件延伸引導目標。
- guidance 只使用有效歷史路徑範圍，排除尚未填入的零列。
- WindowManager 依局部單調進度更新，接近路段尾端時提前提供連續下一段。

問題指的是飛機越過「目前局部路段的末點」，使引導目標落到後方，並非已完成整條任務路線。風會改變地速與進度，但無風也可能遇到此情況，因此上述處理不應限定於有風階段。已納入正式 SLX 的修正直接使用，不再次套用舊候選轉換函式；未部署的重疊 window 候選不納入。

## 未來實作與驗證邊界

純腳本重跑應建立新 run、初始化新 agent，固定並記錄正式環境版本與 SHA、課程及執行設定，從第一階段開始；不以既有 recovery 分支的訓練歷史替代從頭驗證。此次決定不另行更改 reward 公式、終止門檻或 PPO 參數。

既有 Agent31600 在目前環境的前三階段單 seed 評估均跑滿 3000 步，全部評估共 43 個不同組合跑滿；這支持既有能力在此次測試中保留，但不證明新 agent 從頭訓練能穩定收斂或整套課程已合格。仍需另行驗證從頭訓練及各階段評估；舊環境與新環境分數不能直接當成同一條學習曲線。

本次僅記錄未來重跑方向，不實作入口腳本、不修改 runtime 或既有 run、不啟動訓練；未授權 commit 或 push。沿用先前在目前方案確認合格後，再整理純腳本重跑驗證的安排。
